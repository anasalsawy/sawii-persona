# 03 · One turn

A single message, end to end. The shape of the whole system in one picture.

```
 you send a message
   │
   ├─► consultants start thinking        (parallel — the moment the message lands, never awaited)
   │
   ├─► the mind loads:  persona · narrative · open loops · integrity record · C's profile
   │                    recall slice (five lanes, stitched) · thoughts on its mind
   │                    verbatim tail (server-side, any device) · the running clock
   ▼
 A streams the answer
   │     ──(tool)── fetch_consults   : bounded wait, returns what's ready + who's still working
   │     ──(tool)── check_clock      : the live seconds
   │     ──(tool)── try_to_remember  : asks B for something on the tip of its tongue
   │     ──(tool)── delegate_task    : hands heavy work to the workshop
   │     ──(tool)── work_in_background: starts a job on the background lane
   │     private suffix ⟦feel: …⟧    : removed before you ever see it → A's chord
   ▼
 you have your answer  ─────────── nothing below blocks you ───────────
   │
   ├─ B reviews   → verdict (integrity record) · REQUIRED correction · collateral · loops
   │                · conscience note · afterthought from late consults · revisit-and-revise
   ├─ C observes  → your chord · notes · readings · hypotheses · entities · reinterpretations
   │                · brief for B · prediction of your next message
   ├─ A writes    → the fact layer (its diary)
   ├─ B rules     → standing requests ("keep it short") · dropped threads · regulation of A's feeling
   ├─ B deep      → a slower, wider look back, now that A has answered → kept for next time
   └─ juice       → the raw turn, kept byte-exact, if it was emotionally high-variance
```

## The one rule that makes it a *mind*, not a pipeline

**A never searches its own memory.** Memories *arrive* to A — written and chosen by the other minds —
the way a memory surfaces in a person. A does not go looking; it is *reminded*. Everything that
arrives is rendered from the stored record, with exact quotes and dates, so A weighs it instead of
obeying it.

## What the person never sees

Everything below the line — B's review, C's observation, the corrections, the conscience note, the
juice — happens *after* you have your answer, on background tasks. **Nothing below the line blocks
you.** The one exception is deliberate and rare: if a mind finds something important *while A is
still speaking*, it reaches A at a sentence end, and A folds it into the same reply — the way a
thought catches up with you mid-sentence.

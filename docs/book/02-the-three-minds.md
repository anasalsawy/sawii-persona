# 02 · The three minds

A companion made of three minds. One **speaks**. One **checks and remembers**. One **watches how
you feel**. They run at the same time, so the companion can do what a single model cannot: remember
something while it is still talking, catch its own mistake mid-sentence, notice your tone before it
finishes answering, and keep thinking after you leave.

```
                     ┌──────────── the person (one key = one being, any device) ────────────┐
                     │        app · voice · SMS · WhatsApp · phone · email · Telegram        │
                     └──────────────────────────────┬───────────────────────────────────────┘
                                                    │
                  ┌─────────────────────────────────▼─────────────────────────────────┐
                  │  A  THE VOICE       the only part the person ever hears            │
                  │     streams the answer, feels (a chord), uses tools mid-sentence   │
                  │        ▲ inner voice at sentence ends                               │
                  ├────────┼───────────────────────────────────────────────────────────┤
                  │  B  THE ADJUTANT    remembers, checks, keeps the to-do list        │
                  │     searches the past WHILE A talks · live-checks A · reviews it   │
                  ├────────────────────────────────────────────────────────────────────┤
                  │  C  THE OBSERVER    reads the person: tone, feelings, patterns     │
                  │     gut read WHILE A talks · notes/readings/hypotheses after       │
                  └────────────────────────────────────────────────────────────────────┘
                         one memory · one clock · one thought stream · one sleep
```

## The roles today

| | **A — the voice** | **B — the adjutant** | **C — the observer** |
|---|---|---|---|
| **Speaks to the person** | yes — only A | never | never |
| **While A talks** | streams the answer | searches the past, live-checks finished sentences | gut read: tone, surprise |
| **After A answers** | writes the *fact* layer (its diary) | verdict, correction, collateral, loops, rules, conscience, afterthought | notes, readings, your feeling, hypotheses, entities, reinterpretations, brief for B |
| **While you are away** | composes outreach, dreams | reflects, audits outreach, builds the calibration map | psych profile, mirror of A's habits |
| **Writes to memory** | `fact` layer only | `collateral`, `afterthought`, loops, rules, verdicts | `note`, `reading` layers, hypotheses, entities |

**Advice flows down the chain** (C → B → A). **Authorship stays flat**: each mind writes only its
own layer; nobody edits upstream. B never rewrites C's reading of you; A never edits B's loops.

**Dissent is the job.** B lets nothing false stand, including A's. C tells B what B *needs* to hear,
not what B *wants* to hear. A junior mind overrules a senior one only with your own recorded words.

## The intended direction (the re-architecture)

The owner's direction is a deliberate re-balancing of the three minds:

| Function | Today | **Intended** |
|---|---|---|
| Talks, reasons, remembers | A | **A** (the mind) |
| Verification — verdict, findings, correction, the meter | B | → **C** (the verifier) |
| Conscience note, affect regulation | B | → **C** |
| Collateral memory ("what A missed") | B | → **C** |
| Psych read — chord, hypotheses, notes, readings | C | **C** (stays) |
| Open loops, reminders, tasks | B | **B** (the hands) |
| Execution — tools, workshop, background work | workshop | → **B** (the hands) |

The reasoning behind it is a principle, not a taste: **the mind that does the work must not grade
its own work.** An executor that verifies itself is a closed loop. So verification moves to the mind
whose job is *checking* — and that mind becomes the teacher the aging design needs.

> **Note for the owner.** This re-architecture is *intended, not yet built.* It is the one structural
> change the rest depends on. Two details are still open and are tracked in `10-open-questions.md`:
> whether C keeps the psych read alongside verification, and what model each mind runs after the swap.

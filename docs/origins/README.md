here unchanged so the history is never lost again. They describe the earlier companion experiment
built *inside* the Dual-Lobe proxy. Sawii Persona re-implements these ideas as its own product;
where they differ, `../DECISIONS.md` is authoritative.

`entities-supersession` and is not on GitHub. Its content is reconstructed from the conversation
in `../DECISIONS.md` and implemented in `src/sawii_persona/memory/`.
